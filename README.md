#  Medical Image Classification (Pneumonia Detection)

This project is a Deep Learning-based system that classifies chest X-ray images as **PNEUMONIA** or **NORMAL** using a Convolutional Neural Network (CNN).

---

##  Features
- Train CNN model on medical images
- Image preprocessing using OpenCV
- Binary classification (Pneumonia vs Normal)
- Model evaluation (accuracy, loss)
- Predict new images using trained model

---

##  Tech Stack
- Python
- TensorFlow / Keras
- OpenCV
- NumPy
- Matplotlib
